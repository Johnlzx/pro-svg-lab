01 / THE MECHANISM

颜色没有流动。
流动的是颜色的输入。

把字母当作一张地形图：轮廓决定地形，移动的灰度渐变改变“海拔”，查找表负责把每个高度染成不同颜色。

A

先制造连续的灰度场

字形透明度经过三个尺度的模糊与相减，得到宽窄不同的内边缘。叠加后，平面字形拥有了柔和的明暗坡度。这里的“浮雕”来自计算，并没有三维模型。

SourceAlpha → blur → subtract → merge
B

让斜向扫描改变这个场

一个倾斜 −35° 的重复灰度渐变持续平移。它叠在轮廓上，亮的区域逐渐变白，暗的区域恢复深色。轮廓不动，也会产生软化、熔融和重新凝结的错觉。

linearGradient + animateTransform → overlay
C

把亮度当作色谱的索引

最终模糊把明暗连成平滑过渡，细噪声打散过于光滑的色带。三个通道各查一次表：同一个灰度值被翻译成 R、G、B，形成沿边缘生长的彩色等高线。

feComponentTransfer → feFuncR / G / B
较暗 / 0灰度输入 → 颜色输出较亮 / 1

把柔度设为 1，再慢慢拉到 13：你会直接看到，模糊不是丢失细节，而是在生成材质需要的连续空间。

03 / WHAT SVG REALLY BUYS YOU

小的是描述，
不是计算量。

SVG 的潜力在于组合：几何、遮罩、模糊、颜色、置换与时间，可以组成一条可编辑的图像处理链。用少量描述生成持续变化的画面，是它远超静态图标的地方。

滤镜阶段仍要栅格化。大尺寸、多个噪声层和宽滤镜区域会增加每帧开销；没有 JavaScript，并不意味着没有渲染成本。实验室把置换与光照作为可选扩展，默认保留原作的简洁结构。
